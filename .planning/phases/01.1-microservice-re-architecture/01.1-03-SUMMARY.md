# Phase 01.1 Plan 03: API gateway and Organization extraction Summary

**All external traffic now enters through a thin FastAPI gateway that routes by path prefix, 404s `/internal`, unknown and traversal paths without forwarding them and maps upstream failures to 503/504, while Organization runs as its own JWKS-verifying service on organization_db and publishes authenticated, clinic-scoped, inactive-aware `/internal` reference lookups.**

## Accomplishments

- **Gateway** (`services/gateway`): `ROUTE_TABLE` maps `/.well-known/jwks.json`, `/api/auth`, `/api/admin` to Identity, `/api/clinics` to Organization, `/api/providers` to Provider and `/api/patients` to Patient; there is no `/internal` prefix. Prefixes match on a segment boundary (`/api/clinicsX` is a 404). `is_safe_path` refuses dot segments, `//`, backslash, NUL and raw `%2e` / `%2f` / `%5c` / `%00`. The upstream URL is built from `scope["raw_path"]`, so an encoded `?` can never become a query string. One un-retried upstream call with an explicit timeout; `httpx.TimeoutException` -> 504, any other `httpx.TransportError` -> 503. Logs carry the upstream name and path only.
- **Organization** (`services/organization`): clinics and departments moved from Identity with `git mv` (routes, RBAC, audit calls and response shapes unchanged); own `OrganizationSettings` bound to `ORGANIZATION_DATABASE_URL`, own `OrganizationBase`, `organization_0001` baseline whose downgrade is the exact inverse; `app.state.key_resolver = JwksClient.from_settings(settings)`.
- **Internal lookups**: `GET /internal/clinics/{id}` returns `{id, is_active}` (ADMIN, FRONT_DESK) and `GET /internal/departments/{id}` returns `{id, clinic_id, is_active}` (ADMIN, PROVIDER). Missing and out-of-clinic-scope ids give the same `{"detail": "not found"}`. Inactive rows are reported, not hidden, so a calling service can answer 422 (D-06). `libs/auth/internal.py` holds `InternalCaller`, `require_internal_caller` and `clinic_scope_permits`.
- **Harness**: `ENTRY_SERVICE = "gateway"`, so the identity and libs suites now run through the gateway too (88 tests, one adapted, see Deviations).
- **Verification:** `pytest tests/identity/ tests/libs/ tests/organization/ tests/gateway/` = 177 passed; `pytest tests/ -k "not integration and not e2e"` = 92 passed (85 deselected); the Organization migration round-trips; every task acceptance criterion passes (test counts: tracer 4, internal lookups 17, routing 39 with no containers).
