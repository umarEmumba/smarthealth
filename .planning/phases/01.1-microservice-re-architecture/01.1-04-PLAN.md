## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → gateway | Request volume and inbound trace headers are attacker-controlled |
| gateway → Redis | The limiter's state store; its outage must not take the platform down or disable protection silently |
| package registry → build | New third-party code enters every service image |
