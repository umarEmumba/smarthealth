## Flagged Assumptions (edge-probe items not auto-resolvable)

- **PPL-04 (unclassified):** Reads are served from the owning service's own database with no cache, so read-after-write is consistent within a service. No cross-service read consistency is promised, because reads return ids only (D-07) and a client combining data from several services may briefly see a clinic deactivated after the patient row was read. Needs confirmation from the user or mentor that this is acceptable for PPL-04 ("consistent, up-to-date state").
