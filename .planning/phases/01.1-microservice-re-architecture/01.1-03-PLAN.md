<objective>
Stand up the API gateway as the single ingress and extract Organization (clinics, departments) onto its own database, so every existing test from this point on travels client → gateway → owning service (roadmap SC3/SC5; D-01, D-07). Organization verifies tokens locally from Identity's JWKS, re-applies RBAC itself, and publishes the two internal reference-lookup endpoints the cross-service integrity checks in plans 01.1-05..07 will call (D-05 consumer side; D-06 no-cascade deactivation).

Purpose: This is the first time two data-owning services and the gateway run together; it proves local JWKS verification in a non-Identity service, the gateway's routing/isolation guarantees, and the internal-endpoint contract before Patient and Provider depend on them.
Output: Gateway (routing, safe-path checks, header hygiene, 503/504), Organization service with fresh baseline and internal lookups, `libs/auth/internal.py`, relocated clinic/department tests plus new routing/isolation/revocation tests.
</objective>
