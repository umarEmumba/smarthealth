A. tools/validation-ui/serve.py (stdlib only; module docstring states purpose, usage and the security rules).
 - Constants: BIND_HOST fixed to "127.0.0.1" with NO host option anywhere (not CLI, not env, not a function parameter); DEFAULT_PORT 8099; DEFAULT_GATEWAY_URL "http://localhost:8000"; BODY_LIMIT_BYTES 1048576; UPSTREAM_TIMEOUT 30.0 as a module global read at request time (tests monkeypatch it); STATIC_ROUTES allowlist mapping request path to (file name, content type) for "/" and "/index.html" (index.html), "/lib.js", "/core.js", "/panels_booking.js", "/panels_ops.js" (JavaScript, text/javascript; charset=utf-8) and "/style.css" (text/css). Files are resolved only from the directory containing serve.py and only through this table, never from request-derived text; a listed file that does not exist yet answers 404 JSON so the allowlist can be complete from this task on. GET /favicon.ico answers 204.
 - make_server(gateway_url=DEFAULT_GATEWAY_URL, port=DEFAULT_PORT) returns a ThreadingHTTPServer bound to (BIND_HOST, port) with daemon_threads true; port 0 picks a free port. gateway_url is parsed with urllib.parse and must be http or https with a host and NO userinfo, else ValueError. After binding, compute the allowed Host values "127.0.0.1:<bound port>" and "localhost:<bound port>" and the allowed Origin values (same with "http://" prefix) and store them on the handler class bound to this server.
 - One handler method serves GET, POST, PUT, PATCH, DELETE, HEAD and OPTIONS (BaseHTTPRequestHandler subclass; leave the default HTTP/1.0 close-delimited responses). Order of checks: (1) Host header must be in the allowed set (case-insensitive) else 403 {"detail":"forbidden host"}; (2) if an Origin header is present it must be in the allowed set else 403 {"detail":"forbidden origin"}; both run before anything else, static files included, and are the DNS-rebinding / cross-site guard (the proxy adds NO CORS headers, ever). (3) GET/HEAD on a STATIC_ROUTES path returns the file with Content-Type, Content-Length, Cache-Control no-store, X-Content-Type-Options nosniff, Referrer-Policy no-referrer, X-Frame-Options DENY and Content-Security-Policy "default-src 'none'; script-src 'self'; style-src 'self'; connect-src 'self'; img-src 'self' data:; base-uri 'none'; form-action 'none'; frame-ancestors 'none'"; any other method on a static path is 405 JSON. (4) GET /_ui/config returns JSON {"gateway_url": <configured URL, no credentials>}. (5) A request target whose raw text starts with the literal "/api/" is proxied; anything else (including absolute-form targets such as "http://host/api/x", and unknown paths) is 404 {"detail":"not found"} and never reaches the upstream.
 - Proxy rules. Body: Content-Length parsed as an integer (non-integer or negative -> 400), larger than BODY_LIMIT_BYTES -> 413, any Transfer-Encoding on the request -> 411; read exactly that many bytes. Upstream request: same method; the raw target (path and query verbatim, no re-encoding or normalisation) appended to the gateway URL's own base path; headers = every client header EXCEPT the hop-by-hop set (connection, keep-alive, proxy-authenticate, proxy-authorization, te, trailer, trailers, transfer-encoding, upgrade, plus any header named inside Connection), host, content-length and accept-encoding (Host to the upstream is the gateway's own host:port, which http.client derives). Authorization, Idempotency-Key, Content-Type and Accept therefore pass untouched. Use http.client (HTTPConnection or HTTPSConnection per scheme, timeout UPSTREAM_TIMEOUT), not urllib: it neither follows redirects nor raises on 4xx/5xx, so 3xx/4xx/5xx pass through as the gateway produced them. Response: same status and reason; every upstream header via the repeated-header list (not a dict) except hop-by-hop, content-length, server and date (send_response already emits Server and Date), so X-Total-Count, Location, Retry-After and repeated headers survive; Content-Length recomputed from the body bytes; HEAD sends upstream's headers incl. its Content-Length and no body; 204 and 304 send no body and no Content-Length. Failures: http.client.InvalidURL -> 400; socket timeout -> 504; any other OSError/HTTPException -> 502; JSON {"detail": ...} naming the gateway base URL, never a traceback.
 - log_message writes only "METHOD path status" style lines to stderr: never headers, bodies or tokens.
 - main(argv=None): argparse with --port (default env VALIDATION_UI_PORT else 8099) and --gateway-url (default env GATEWAY_URL else DEFAULT_GATEWAY_URL); an invalid gateway URL prints a message to stderr and exits 2; prints one banner line (flushed immediately) with http://127.0.0.1:<port>/ and the gateway; serve_forever until KeyboardInterrupt; `if __name__ == "__main__": raise SystemExit(main())`. Must run on Python 3.12 (.venv) and the system python3.

B. tools/validation-ui/lib.js: a classic script (no modules, no DOM access at load) that attaches pure helpers to globalThis.VUI (create it when absent) so core.js can use them and Node can load the file in a vm context. ## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser (any web page the user has open) -> serve.py on 127.0.0.1:8099 | A malicious page can try to make the user's browser call the loopback proxy (cross-site request, DNS rebinding) |
| serve.py -> gateway (GATEWAY_URL) | Request targets and headers originate from the browser; the proxy must not become an open proxy or SSRF primitive |
| gateway response content -> DOM | Response bodies carry server-controlled text (names, error details) rendered in the page |
| tokens in the page (sessionStorage, log pane) | Access and refresh tokens are visible to anything that can run script in the page |
| seed_demo_users.py -> gateway | Creates privileged accounts using admin credentials from the environment |
