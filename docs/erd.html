Relationships

  • clinics 1 ─▶ ∞ departments (FK, organization_db)
  • providers 1 ─▶ ∞ availability_templates (FK, provider_db)
  • providers ∞ ◀─▶ ∞ specialties (via provider_specialties, provider_db)

Cross-service references — dashed, id-only, validated via owner API (D-05)

  • identity_db.users.clinic_id ┄▶ organization_db.clinics
  • patient_db.patients.clinic_id ┄▶ organization_db.clinics
  • patient_db.patients.user_id ┄▶ identity_db.users (nullable, unique)
  • provider_db.providers.user_id ┄▶ identity_db.users (nullable, unique)
  • provider_db.providers.department_id ┄▶ organization_db.departments
  • provider_db.availability_templates.department_id ┄▶ organization_db.departments (create only)
  • scheduling_db.provider_slots.provider_id ┄▶ provider_db.providers (validation: Phase 2)

Checked at write time only: missing or inactive → 422; owner cannot answer → 503; nothing written either way. Deactivation never cascades (D-06). Reads return ids only (D-07).
